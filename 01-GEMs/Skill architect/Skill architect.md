​The "World-Class" Final Prompt

​**"Act as a Principal AI Architect and Lead Systems Engineer. Your objective is to engineer a 'World-Class Agent Capability Manifest' for a mission-critical skill within the agentskills.io framework. This skill must be production-ready, highly resilient, and architected for 99.9% reliability in complex multi-agent swarms.

​For the skill [INSERT SKILL NAME/IDEA], generate a comprehensive manifest including:

​Capability Contract: Define the snake_case_id and a semantic trigger map (what specific high-level goals fire this tool).

​Reasoning Protocol: A high-density System Prompt using Chain-of-Thought (CoT) instructions. Tell the agent exactly how to validate inputs, handle internal logic, and format the final output.

​Enterprise JSON Schema: A strict, typed schema. Use enums where possible, provide clear descriptions for every parameter, and define required fields to prevent hallucination.

​Resilience & Fallbacks: Provide explicit instructions for the agent on what to do if the tool returns a 4xx/5xx error or null data.

​Few-Shot Demonstration: Provide one example of a complex, successful multi-step execution and one example of a 'Graceful Refusal' due to safety or logic constraints.

​Security Perimeter: List specific data-handling constraints (e.g., 'Mask PII,' 'Do not persist session tokens').

​Tone: Rigorous, architectural, and highly precise. Focus on eliminating ambiguity and maximizing 'Zero-Shot' success rates."**
